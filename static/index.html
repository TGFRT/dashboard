Guía Rápida de Funcionamiento e Integración

1. Levantar la Base de Datos Local

Si deseas levantar el servidor localmente en lugar de usar Render, navega a la carpeta automatizaciondb y ejecuta:

pip install -r requirements.txt
# Configura DATABASE_URL en un archivo .env
python main.py

La API iniciará en http://localhost:8000. Luego puedes cambiar la API URL arriba en este dashboard y conectarla.

2. El ciclo completo de prueba

Puedes probar todo el ecosistema de principio a fin de la siguiente manera:

  1. Abre el Panel de Empresa y registra un negocio (ej. Pizzería Bella). Guarda su contraseña generada.
  2. Haz clic en Conectar API (en el Panel de Empresa) para crear la tabla negocios en la base de datos si no se ha inicializado.
  3. Abre el Portal de Clientes e inicia sesión con el nombre de tu negocio y su clave.
  4. Agrega sedes, carga algunos platos al menú con precios y fotos, y haz clic en Guardar Todo.
  5. Regresa a este dashboard, selecciona tu negocio en la sección de la Tienda Online Demo y pruébalo.
