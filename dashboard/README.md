# Dashboard Repository

Este repositorio contiene la UI del panel de control empresarial que centraliza la gestión de los tres productos:
- `automatizaciondb` (API)
- `PANELEMPRESA` (panel B2B)
- `PANELCLIENTES` (panel B2C)

## Estructura
- `index.html` – página principal del dashboard.
- `style.css` – estilos premium con glassmorphism y animaciones.
- `script.js` – lógica de conexión a la API y control de UI.
- `render.yaml` – configuración de despliegue en Render.
- `Dockerfile` – contenedor Node/NGINX.
